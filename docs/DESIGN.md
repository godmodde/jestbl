# DESIGN — «Видно», школа РЖЯ

Живой дизайн-документ (Design Documentation по CLAUDE.md). Решения интервью — в [CHECKPOINT.md](CHECKPOINT.md), исходное ТЗ — в [../CLAUDE.md](../CLAUDE.md).

**Итоговое ощущение (ТЗ, ч. IX):** «Я вижу жест. Я понимаю, что он означает. Я могу попробовать. Если не получилось — посмотрю ещё раз. Я знаю, что делать дальше».

**Бизнес-решения (CLAUDE.md, п. 6):** это не магазин. Корзины, оформления заказа, фильтров каталога и аккаунта нет — нет товаров и регистрации. Поиск есть (словарь).

### Навигация

- **Главная:** логотип (без расшифровки: «Русский жестовый язык» стоит надзаголовком первого экрана) · пилюля с якорями разделов (Как учимся `#how`, Направления `#directions`, Путь `#path`, Попробовать `#platform`, Вопросы `#faq`; один список `SECTIONS` на шапку и подвал) · справа страницы: Словарь, Обучение, значок кабинета. Пилюля после 160 px прокрутки переезжает вниз и подсвечивает раздел на экране; на телефоне она шире экрана и листается вбок, текущий раздел выезжает в середину, края растворяются. «Отзывы» `#reviews` — по тому же условию, что и раздел (сейчас только демо); преподаватели получат якорь, когда станут настоящими. Пилюля в шапке до 1400 px компактнее (поля 12, кегль 14). Текущий раздел — по линии на трети высоты экрана.
- **Платформа, десктоп:** логотип · Учиться · Словарь · Повторение (с числом карточек) · Прогресс. Активный пункт — заливка тушью. «Учиться» активен и на `/alphabet`, `/adults`.
- **Платформа, телефон:** нижняя панель из тех же 4 пунктов со значками. В уроке, практике, экзамене и проверке букв панели нет — своя ссылка назад.
- **Детский мир:** своя шапка без взрослого меню (решение заказчика 2026-10-10): «Видно» + метка «Детям» слева, «Выйти» → `/learn` справа. Ребёнок не потеряется, взрослый выйдет одной кнопкой. С 2026-11-10 справа ещё копилка «★ N» (сумма лучших результатов по темам) и чип возраста «3–5 лет · сменить» — сброс возвращает к выбору. Копилка обновляется сразу после экзамена (`router.refresh()` после сохранения).
- **Кнопки «Войти» нет:** аккаунтов в v1 нет, а нерабочих кнопок по ТЗ быть не должно.

## 2. Логика урока (утверждено 2026-10-09)

Для каждого жеста урока: **01 Смотрим** (видео, скорость, повтор) → **02 Разбираем** (карточка) → короткая проверка «Что означает этот жест?». После всех жестов идёт **03 Пробуем**, общая практика по уроку:

1. Узнать жест по видео: выбрать значение из 4 вариантов.
2. Найти видео по значению: выбрать из 3 видео.
3. Повторить карточку: вспомнить жест → открыть ответ → «Повторить / Почти запомнил / Знаю».

- **Ошибка:** «Пока не совсем. Посмотрите ещё раз на движение.» + «Попробовать ещё раз». Видео открывается прямо в задании, без возврата к началу урока.
- **Верный ответ:** «Верно.» и переход дальше. Без шоу.
- **Неверные варианты** берутся из жестов той же темы.
- **Состояние урока** (этап и жест) сохраняется. После перезагрузки человек возвращается туда же.
- **Карточка в уроке** — та же, что в словаре, с кнопками «В избранное» и «В повторение» (ТЗ, п. 18).

## 3. Повторение (интервальное)

- В очередь попадает каждый жест из пройденного урока, плюс жесты, добавленные из словаря вручную.
- **Самооценка:** «Повторить» → снова через 10 минут; «Почти запомнил» → интервал × 1,5 (минимум 1 день); «Знаю» → интервал × 2,5 (минимум 3 дня).
- **Ошибка в задании «Узнать жест»** = «Повторить».
- Серий, наград и напоминаний нет (ТЗ, п. 22).

## 4. Данные (PostgreSQL)

Единая карточка жеста (ТЗ, п. 20) используется в уроке, словаре и повторении.

- `signs`: slug, title, gloss, meaning, how_to (nullable), context, notice, category, video_url (demo), source_url, needs_review
- `sign_similar`: связи «похожие жесты»
- `topics`, `lessons`, `lesson_signs` (порядок)
- `devices`: анонимный ID из cookie
- `sign_state`: device × sign → favorite, learned_at, interval, due_at, reps
- `lesson_progress`: device × lesson → stage, sign_index, completed_at
- **Миграция 002 (`db/migrations/002_directions.sql`, три направления на одной базе):** `topics.direction` (alphabet / adults / kids) · `lessons.kind` (lesson; в детской теме — станции find / pair / feed / route / diff / exam) · `signs`: kind (object / action / interaction / phrase / letter / other), level 1–3, tags, picture (картинка для детских игр), angles (ракурсы `[{label, url}]`), sort_key («ё» как «е») · `sign_categories`: один жест — много категорий без дублей · `sign_similar.kind` (similar / related) · `exam_attempts`: device × (категория | урок) → total, correct, stars 1–3, mistakes
- **Миграция 004 (`004_star_tiers.sql`, звёзды детям 2026-11-10):** `exam_attempts.stars` ∈ {3, 5, 10} вместо 1–3 (старые 1/2/3 переписаны в 3/5/10). Ступени (`lib/exam.ts`, `stars()`): прошёл до конца — 3, от 60 % верных — 5, без ошибок — 10. В копилку идёт лучший результат по каждой теме, повтор не накручивает (`getStarBank`)
- **Миграция 003 (`003_kids_alphabet.sql`, детский алфавит 2026-11-10):** `topics.direction` + `kids-alphabet` — шесть групп букв (`bukvy-…`, из тех же групп, что у взрослых, жесты общие) · `lessons.kind` + `trace` / `choose` / `show`. Следующая группа открывается после теста предыдущей (звёзды > 0); буква вклеивается наклейкой, когда верно показана в тесте (есть в попытке и не в её ошибках)

API для будущего приложения: `/api/v1/…` (уроки, жесты, поиск, состояние устройства). Веб использует те же функции данных.

## 5. Компоненты

Соответствие обязательным компонентам CLAUDE.md, п. 7: карточка товара → SignCard · фильтры → категории и вкладки словаря · навигация → SiteHeader, PlatformNav, TabBar · кнопки CTA → Button / ButtonLink · модальные окна — нет: ни одна задача не требует прерывания · формы → поиск словаря · бейджи → «Черновик · требует проверки», число карточек у «Повторения», «готовится» у тем.

## 6. Визуальная система

- **Цвет:** фон `#F5F1EA`, второй оттенок фона `#ECE5D9`, поверхность `#FBF9F5` (она же фон первого экрана и шапки главной), подложка видео первого экрана — шалфей `#E8EFEA` → `#D9E6DE` (текст на ней 6,85:1), текст `#1D1C1A`, второй текст `#4E4A43` (пояснения, подписи), вторичный текст `#67635B`, линии `#D9D1C3`, фон пустого кадра `#DED6C8`, дорожка (наведение, неактивный чип) `#E9E3D8`, акцент `#1F5E4B` (нажатие — `#184C3D`), мягкий акцент `#E6EEE9`, тёплая подложка `#F3E9D7`, звезда `#B07A12` (только детский мир, см. ниже). Токены — `@theme` в `app/globals.css`. Акцент только для главных действий и состояний (на первом экране — только кнопка). Декор — тушью. Активные переключатели — контур, не заливка. Ошибки не красные, а нейтральные.
- **Шрифты:** Geologica вариативная (оси CRSV, slnt) + Onest (текст и интерфейс, 400–600), self-hosted через next/font. Заголовки — Geologica 600. «Голос жеста» (`.type-gloss`) — курсив той же гарнитуры (`CRSV 1`, наклон −10): подпись жеста и слово «*жеста.*» в H1 первого экрана. Ось SHRP убрана — на глаз неразличима (проверка 2026-10-09). Шкала: 80 (H1 главной) / 48 / 44 (подпись жеста на первом экране) / 32 / 24 / 20 / 17 / 15 / 13.   - *Детский альбом по наброску Леры* (`components/kids-board.tsx`): блок с дугой «← Тема →» (стрелки листают темы), слева две карточки — жест в пушистой рамке и его картинка, в центре слово (плюш), звёзды и игры-подушки, справа список жестов темы. Телефон: дуга, видео, слово с картинкой, игры, список.
  - *Новые игры* (на станциях прежних механик с тем же навыком — прогресс и наклейки без изменений базы, `NEW_GAMES`):
    - «Лопни шарики» вместо «Найди жест»: жест на видео — лопни шарик с той же картинкой; шарики медленно плывут вверх по кругу (cqh — высота неба), без таймера; без анимации висят на месте;
    - «Мемори» вместо «Собери пару»: карточки рубашкой вверх, пара — видео жеста и картинка, переворот по оси Y;
    - «Найди в комнате» вместо «Накорми друга»: комната с игрушками (стена, окно, полка, ковёр, кресло) — найти предмет по жесту;
    - «История с другом» вместо «Пройди маршрут»: мишка идёт к домику, жест — в облачке его речи, верный ответ кладётся в рюкзак, мишка шагает дальше.
    - Малышам 3–5 — меньше вариантов и шагов (2 шарика, 2 пары, 4 предмета).
