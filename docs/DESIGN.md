# DESIGN — «Видно», школа РЖЯ

Живой дизайн-документ (Design Documentation по CLAUDE.md). Решения интервью — в [CHECKPOINT.md](CHECKPOINT.md), исходное ТЗ — в [../CLAUDE.md](../CLAUDE.md).

**Итоговое ощущение (ТЗ, ч. IX):** «Я вижу жест. Я понимаю, что он означает. Я могу попробовать. Если не получилось — посмотрю ещё раз. Я знаю, что делать дальше».

**Бизнес-решения (CLAUDE.md, п. 6):** это не магазин. Корзины, оформления заказа, фильтров каталога и аккаунта нет — нет товаров и регистрации. Поиск есть (словарь).

### Навигация

- **Главная:** логотип (без расшифровки: «Русский жестовый язык» стоит надзаголовком первого экрана) · пилюля с якорями разделов (Как учимся `#how`, Направления `#directions`, Путь `#path`, Попробовать `#platform`, Вопросы `#faq`; один список `SECTIONS` на шапку и подвал) · справа страницы: Словарь, Обучение, значок кабинета. Пилюля после 160 px прокрутки переезжает вниз и подсвечивает раздел на экране; на телефоне она шире экрана и листается вбок, текущий раздел выезжает в середину, края растворяются. «Отзывы» `#reviews` — по тому же условию, что и раздел (сейчас только демо); преподаватели получат якорь, когда станут настоящими. Пилюля в шапке до 1400 px компактнее (поля 12, кегль 14). Текущий раздел — по линии на трети высоты экрана.
- **Платформа, десктоп:** логотип · Учиться · Словарь · Повторение (с числом карточек) · Прогресс. Активный пункт — заливка тушью. «Учиться» активен и на `/alphabet`, `/adults`.
- **Платформа, телефон:** нижняя панель из тех же 4 пунктов со значками. В уроке, практике, экзамене и проверке букв панели нет — своя ссылка назад.
- **Детский мир:** своя шапка без взрослого меню (решение заказчика 2026-10-10): «Видно» + метка «Детям» слева, «Выйти» → `/learn` справа. Ребёнок не потеряется, взрослый выйдет одной кнопкой.
- **Кнопки «Войти» нет:** аккаунтов в v1 нет, а нерабочих кнопок по ТЗ быть не должно.

## 2. Логика урока (утверждено 2026-10-09)

Для каждого жеста урока: **01 Смотрим** (видео, скорость, повтор) → **02 Разбираем** (карточка) → короткая проверка «Что означает этот жест?». После всех жестов идёт **03 Пробуем**, общая практика по уроку:

1. Узнать жест по видео: выбрать значение из 4 вариантов.
2. Найти видео по значению: выбрать из 3 видео.
3. Повторить карточку: вспомнить жест → открыть ответ → «Повторить / Почти запомнил / Знаю».

- **Ошибка:** «Пока не совсем. Посмотрите ещё раз на движение.» + «Попробовать ещё раз». Видео открывается прямо в задании, без возврата к началу урока.
- **Верный ответ:** «Верно.» и переход дальше. Без шоу.
- **Неверные варианты** берутся из жестов той же темы.
- **Состояние урока** (этап и жест) сохраняется. После перезагрузки человек возвращается туда же.
- **Карточка в уроке** — та же, что в словаре, с кнопками «В избранное» и «В повторение» (ТЗ, п. 18).

## 3. Повторение (интервальное)

- В очередь попадает каждый жест из пройденного урока, плюс жесты, добавленные из словаря вручную.
- **Самооценка:** «Повторить» → снова через 10 минут; «Почти запомнил» → интервал × 1,5 (минимум 1 день); «Знаю» → интервал × 2,5 (минимум 3 дня).
- **Ошибка в задании «Узнать жест»** = «Повторить».
- Серий, наград и напоминаний нет (ТЗ, п. 22).

## 4. Данные (PostgreSQL)

Единая карточка жеста (ТЗ, п. 20) используется в уроке, словаре и повторении.

- `signs`: slug, title, gloss, meaning, how_to (nullable), context, notice, category, video_url (demo), source_url, needs_review
- `sign_similar`: связи «похожие жесты»
- `topics`, `lessons`, `lesson_signs` (порядок)
- `devices`: анонимный ID из cookie
- `sign_state`: device × sign → favorite, learned_at, interval, due_at, reps
- `lesson_progress`: device × lesson → stage, sign_index, completed_at
- **Миграция 002 (`db/migrations/002_directions.sql`, три направления на одной базе):** `topics.direction` (alphabet / adults / kids) · `lessons.kind` (lesson; в детской теме — станции find / pair / feed / route / diff / exam) · `signs`: kind (object / action / interaction / phrase / letter / other), level 1–3, tags, picture (картинка для детских игр), angles (ракурсы `[{label, url}]`), sort_key («ё» как «е») · `sign_categories`: один жест — много категорий без дублей · `sign_similar.kind` (similar / related) · `exam_attempts`: device × (категория | урок) → total, correct, stars 1–3, mistakes

API для будущего приложения: `/api/v1/…` (уроки, жесты, поиск, состояние устройства). Веб использует те же функции данных.

## 6. Визуальная система

- **Цвет:** фон `#F5F1EA`, второй оттенок фона `#ECE5D9`, поверхность `#FBF9F5` (она же фон первого экрана и шапки главной), подложка видео первого экрана — шалфей `#E8EFEA` → `#D9E6DE` (текст на ней 6,85:1), текст `#1D1C1A`, второй текст `#4E4A43` (пояснения, подписи), вторичный текст `#67635B`, линии `#D9D1C3`, фон пустого кадра `#DED6C8`, дорожка (наведение, неактивный чип) `#E9E3D8`, акцент `#1F5E4B` (нажатие — `#184C3D`), мягкий акцент `#E6EEE9`, тёплая подложка `#F3E9D7`, звезда `#B07A12` (только детский мир, см. ниже). Токены — `@theme` в `app/globals.css`. Акцент только для главных действий и состояний (на первом экране — только кнопка). Декор — тушью. Активные переключатели — контур, не заливка. Ошибки не красные, а нейтральные.
- **Шрифты:** Geologica вариативная (оси CRSV, slnt) + Onest (текст и интерфейс, 400–600), self-hosted через next/font. Заголовки — Geologica 600. «Голос жеста» (`.type-gloss`) — курсив той же гарнитуры (`CRSV 1`, наклон −10): подпись жеста и слово «*жеста.*» в H1 первого экрана. Ось SHRP убрана — на глаз неразличима (проверка 2026-10-09). Шкала: 80 (H1 главной) / 48 / 44 (подпись жеста на первом экране) / 32 / 24 / 20 / 17 / 15 / 13. Короткие слова привязываются неразрывным пробелом (`lib/typo.ts`). `text-rendering: geometricPrecision` на body — убирает лишний просвет после «т» в Onest. Надзаголовков над заголовками не ставим (SectionHead, SignCard — без них). Единственное исключение закреплено заказчиком: «Русский жестовый язык» над H1 первого экрана (13 px, капс, разрядка 0,14em, вторичный цвет) — задан ТЗ дословно и подтверждён 2026-10-10 на прямой вопрос: «Оставить, как в ТЗ (Рекомендую)» (бриф главной, PINNED). Исключение не переносится на другие экраны. H1 первого экрана — до 96 px (`clamp(44px, 6.2vw, 96px)`), на десктопе тремя строками, «жеста.» курсивом отдельной строкой.
- **Сетка (ТЗ, п. 25):** поля ровно 100 px на десктопе ≥1280 при любой ширине экрана, 40 px на планшете, 20 px на телефоне (решение заказчика 2026-10-10: ограничения ширины контента нет, раньше на 1920 поля вырастали до 340 px). Длину строк держат сами блоки (`max-w` в ch). Видео первого экрана и шага «Смотрим» ограничено высотой окна, чтобы кнопки плеера были видны без прокрутки.
- **Широкий экран (проверено на 1280–2560, 2026-10-10):** лишняя ширина уходит в видео и в промежутки между группами, а не внутрь текста и карточек. С 1536 px текстовая колонка рядом с видео фиксирована: карточка жеста — 600 px (урок, словарь, демо на главной), ответы в заданиях — 520 px; видео забирает остальное и ограничено высотой окна. Сетка словаря добавляет колонки (`auto-fill` от 280 px: 3 на 1440, 4 на 1920, 6 на 2560). «Обучение» с 1280 px — две колонки: слева «продолжить» и уроки, справа «повторить» и «дальше в программе» (порядок в разметке прежний). Реплика «Обучения» на главной — не шире 880 px. H1 главной растёт до 96 px.
- **Кадрирование видео (2026-10-10):** где видео показывает человека крупно (первый экран, «Три направления», «Попробуйте прямо здесь», детский мир) — портретный кадр 5:6 (4:5 на телефоне) с классом `.signer` (app/globals.css): `object-position: 73.5% 50%` центрирует человека (в демо-роликах он стоит правее центра), `scale(1.24)` от точки `50% 32%` уводит вшитый титр за левый край даже у длинных слов; сверху срезается ~6 %, снизу ~13 %. Человек всегда по центру кадра (требование заказчика 2026-10-10). Размытых пятен поверх кадра в этих местах нет. CaptionMask (размытый угол, `backdrop-blur`) остаётся только в заданиях, экзаменах и повторении платформы с кадром 16:9, где титр выдал бы ответ; размер пятна задаёт вызывающий. Оба приёма — временные, под демо-ролики: для своих съёмок без титров пересчитать позицию и убрать маску.
- **Видео:** ролик грузится и играет, только когда рядом с окном (за 400 px), вне окна — пауза; ручную паузу это не снимает. В уроке, словаре и заданиях платформы — 16:9, на телефоне во всю ширину экрана. Ничего не накладываем на руки, лицо и корпус — они всегда открыты; поверх кадра допустим только угол, где фон (маска титра, значок повтора в детской игре). Мотив бренда — уголки кадра тушью 1,5 px. Кнопки плеера — тихие (рамка цвета линий, средний вес); включённое «Медленнее» — заливка тушью с галочкой. В панели повтор «С начала» — только значок рядом с «Медленнее»: строка помещается под узким портретным кадром. Кадр 5:6 на планшете и компьютере (позиция 79%) и 4:5 на телефоне (76%): руки внутри, вшитый титр демо-ролика за кадром, цикл анфасной части ролика 0,3–3,0 с (`clip`), кадр-заставка на середине жеста. Скрытые секции не рендерятся, поэтому ритм сохранится, когда появятся преподаватели и отзывы. Внутри полос рамки-разделители не ставим: границу задаёт смена оттенка. - **Касание:** кнопки и цели ≥44px (в детском мире — от 56 px). Фокус — контур 3px цвета текста.
- **Движение:** UI — 150–250 мс, ease-out (`--ease-out-soft`); переезды и проявления — expo-out `cubic-bezier(.16,1,.3,1)`.

  - *Нажатие:* утилита `press` — кнопка проседает до 0,97 и мягко возвращается.

  - *Отклик на ответ:* верно — галочка с коротким толчком (`.anim-bump`), неверно — покачивание; изученный жест в прогрессе заливается акцентом (`.anim-fill`); пройденная черта буквы заливается по направлению письма (`.trace-fill`).

  - Ширина и высота анимируются только у выведенной из потока подложки и у `::details-content` — сознательно.
  - Содержимое разделов при входе в окно поднимается и проявляется (просьба заказчика).
- **Движение в детском мире:** вклеивание наклейки — вклеивание наклейки (0,7 с), покачивание при ошибке (0,45 с), вспышка рамки (1,8 с); без анимации вспышки нет совсем, сигналом остаётся медленный повтор. На платформе анимация только объясняет результат действия. При `prefers-reduced-motion` всё мгновенно, автозапуск видео выключен.
